Description:

An English translation for Pocket Love. Almost all of the game was translated using Google Translate as well as Jeff's (jeffzzq/jgensler8) limited understanding from watching anime.
Along with the patch, there are notes on the conditions for triggering endings. There are also notes for other game internals (like the phone call system, the calendar + scheduled date system, and the stat initialization code).

The game has been tested the game around 15-20 times end to end, mostly trying to enjoy it and iron out any text formatting. The project is mostly done and enough should be here to enjoy the original work. However, heavy reliance on Google Translate may leave some scenes with a robotic or awkward feeling.

Most of the core game remains the same. To accommodate a nearly 1.5x increase in text quantity, the cartridge type has changed (upgraded to MBC-5) as well as some parts of the text system (accessing text across multiple banks).

Hopefully, the repository's scripts along with the ghidra file might speed up future development if future translations are attempted.

Please Enjoy!
