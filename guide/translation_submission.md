Description:

An English translation for Pocket Love. Almost all of the game was translated using Google Translate as well as my own (limited) understanding from watching anime (~100 days watchtime).
Along with the patch, I have included some of the internal conditions for triggering endings which were used during testing. There are also other notes included for other game internals (like the phone call system, the calendar + scheduled date system, and the stat initialization code).

I have tested the game around 15-20 times end to end, mostly trying to enjoy it and iron out any text formatting. I would say the project is mostly done and enough should be here to enjoy the original work. However, I did rely heavily on translation in and several scenes might still come across robotic. I've done my best to keep the spirit of each character alive though the character limit and line limit of the game posed challenges to complete translation.

Most of the core game remains the same. To accommodate a nearly 1.5x increase in text quantity, the cartridge type has changed (upgraded to MBC-5) as well as some parts of the text system (accessing text across multiple banks).

Hopefully, the repository's scripts along with the ghidra file might speed up future development if future translations are attempted.

Please Enjoy!
